## 目标

用 `Design.md` 的 Apple 设计语言（Action Blue、白/羊皮纸/近黑画布、SF Pro 负字距、pill/hairline 语法）重构 iTrader 的 PySide6 UI 外观。**保留现有高密度信息架构**（侧边栏 + 堆叠页面 + 日志 + 仪表盘），**不改变任何业务逻辑、页面结构、VM 信号、对象名语义**。仅重做视觉呈现（颜色、字体、圆角、间距、按钮语法）。

用户已确认：**默认浅色（Apple 风格基准）**，保留明暗切换。

## 涉及文件

仅视觉层 4 个文件 + 2 个关联点：
1. `src/presentation/theme.py` — **核心**，完全重写两套 QSS 与色板
2. `src/presentation/components.py` — 微调组件样式引用（如 pill 状态点、圆角、边框）
3. `src/presentation/pages.py` — 微调页面内硬编码的少量颜色/样式串
4. `src/presentation/main_window.py` — 默认主题改浅色、顶部操作条/侧边栏微调
5. `src/presentation/viewmodels.py` — 默认 `_dark` 改 `False`，初始日志色映射用浅色
6. `tests/test_main_window_ui.py` — 校验默认主题初始状态断言（如有）

不修改：`domain/`、`application/`、`infrastructure/`、业务逻辑、布局结构、信号连接。

## 设计 token 映射（Design.md → PySide6）

**色板（浅色默认）：**
- 画布 `#ffffff`（canvas）· 羊皮纸 `#f5f5f7`（canvas-parchment）· 珍珠 `#fafafc`（surface-pearl）
- 墨 `#1d1d1f`（ink）· 灰 `#7a7a7a`（ink-muted-48）· 灰80 `#333333`（ink-muted-80）
- 发丝线 `#e0e0e0`（hairline）· 分隔 `#f0f0f0`（divider-soft）· 禁用灰 `#cccccc`（body-muted）
- 交互蓝 `#0066cc`（primary）· focus 蓝 `#0071e3`（primary-focus）· 白 `#ffffff`（on-primary）
- 侧边栏用羊皮纸或白，卡片用白 + hairline 边框

**色板（深色模式）：**
- 画布近黑 `#272729`（surface-tile-1）· 微步浅黑 `#2a2a2c`（tile-2）· 微步深黑 `#252527`（tile-3）
- 正文 `#ffffff` · 次级 `#cccccc`（body-muted）· 灰80 `#d2d2d7`
- 交互蓝用天空蓝 `#2997ff`（primary-on-dark）· 面板微黑
- 侧边栏用 tile-3、卡片用 tile-1 + 发丝线

**圆角：** pill `9999px`（主按钮、状态胶囊、输入框）· `sm` `8px`（工具按钮、侧边栏项）· `lg` `18px`（大卡片）· `md` `11px`（次胶囊）· `none`（全幅块）

**字体：** 全局 `-apple-system, 'SF Pro Text', system-ui, 'Segoe UI', 'PingFang SC', sans-serif`，正文 17px（Design.md 强调），标题 `'SF Pro Display'` + 负字距 `-0.374px`，日志等宽 `'SF Mono', Menlo`

**按钮语法：** 主操作 = Action Blue 实心 pill 白字；次要 = 透明/珍珠底 + 蓝字 + 1px 发丝线 pill；危险/成功 = 语义色实心 pill（保留可读性）；激活态 `transform` 微缩（Qt 用 stylesheet 近似）

## 具体改动

### 1. theme.py（完全重写）
- 重定义颜色常量（浅色/深色两套），保持既有常量名导出兼容（`PRIMARY`, `DANGER`, `SUCCESS`, `WARNING`, `MONO_FONT_FAMILY` 等，pages.py 引用了这些）
- `status_color()` 适配新色板
- `log_colors(dark)` 适配新色板（浅色默认）
- 重写 `APP_QSS`（深色）与 `LIGHT_QSS`（浅色），遵循 Design.md：
  - 主按钮：Action Blue pill 白字，hover 用 focus 蓝，禁用灰
  - 次要按钮：白/珍珠底、发丝线、蓝字 pill
  - 输入框：白底、发丝线、pill 或圆角、focus 用 focus 蓝
  - 卡片 `QFrame#card`：白底 + hairline 边框 + `lg` 圆角，无阴影
  - 侧边栏 `QFrame#sidebar`：羊皮纸/微黑底，选中项发丝线 + 微高亮，无投影
  - 状态胶囊 `#soft`：珍珠/微黑底 + pill 圆角
  - 滚动条、菜单、checkbox、groupbox 同步新色板
- 更新 `qss_for(dark)`（逻辑不变）

### 2. components.py
- `StatusPill`：圆角改 pill，点尺寸微调，初始点色用新中性色
- `Card`：圆角由 QSS 控制（无需改，但确认无内联圆角）
- 确认 `SidebarButton`、`PageHeader` 无硬编码深色色值（当前无内联色，靠 QSS）

### 3. pages.py
- `ServerUrlTestRow._show_help`/help 按钮的内联深色色值 → 改为中性或去掉硬编码深色，避免深色下不可读
- `make_button` 的默认 variant 空 → 主按钮（现默认空，靠 QSS 主样式，保留）
- 页面内 `status_color` 调用无需改

### 4. main_window.py
- `self._dark = True` → `self._dark = False`（默认浅色）
- `_sync_theme_button` 文案逻辑：浅色时按钮显示"深色"（切换入口），深色时显示"浅色"——调整文案判断使其在默认浅色下正确
- 顶部操作条、头部品牌样式随新 QSS

### 5. viewmodels.py
- `_dark = True` → `False`，`_log_colors = log_colors(False)`（初始浅色日志映射）

### 6. tests/test_main_window_ui.py
- 若测试断言初始主题为深色或依赖深色色值，更新为浅色默认预期
- 现有测试主要断言按钮文本与 variant，通常不依赖主题色，需运行确认
